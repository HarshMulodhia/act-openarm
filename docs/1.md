# Setup and Execution Workflow

## 1) Environment Preparation

1. Provision an Isaac Sim environment (e.g., on NVIDIA Brev via Isaac Launchable, or local GPU workstation).
2. Confirm access to VS Code and Isaac Sim viewer.
3. Clone required upstream repositories into a common workspace:

```bash
cd /workspace
git clone https://github.com/enactic/openarm.git
git clone https://github.com/enactic/openarm_isaac_lab.git
git clone https://github.com/tonyzhaozh/act.git
# isaaclab/ is pre-installed in the Isaac Sim image or cloned separately
```

## 2) Install OpenArm Isaac Lab Extension

Install the `openarm_isaac_lab` extension in editable mode so tasks are discoverable by Isaac Lab scripts:

```bash
cd /workspace/isaaclab
python -m pip install -e /workspace/openarm_isaac_lab/source/openarm
```

Available tasks after installation:
- `OpenArmUnimanualReach-v0` — unimanual reach
- `OpenArmUnimanualLift-v0` — unimanual lift
- `OpenArmUnimanualCabinet-v0` — unimanual cabinet
- `OpenArmBimanualReach-v0` — bimanual reach

## 3) Data Collection

1. Select a target OpenArm task.
2. Collect demonstrations with stable control and consistent observation streams.
3. Persist episodes in HDF5 at `openarm_act_project/data/demos_hdf5/` with at least:
   - camera observations
   - joint positions (`qpos`)
   - applied or target actions

```bash
cd /workspace/openarm_act_project
python scripts/collect_openarm_demos.py --config configs/act_openarm_reach.yaml
```

## 4) Training

1. Load demonstrations via `datasets/openarm_isaac_dataset.py` (Isaac HDF5 → ACT inputs).
2. Train ACT using config-driven hyperparameters from `configs/`.
3. Save checkpoints to `checkpoints/openarm_reach_act/`.

```bash
python scripts/train_act_openarm.py --config configs/act_openarm_reach.yaml
```

## 5) Evaluation and Deployment

1. Evaluate checkpoints in the same task configuration used during collection/training.
2. Use chunked action inference for online control.
3. Monitor success metrics and rollout stability before deployment decisions.

```bash
python scripts/eval_act_openarm.py --config configs/act_openarm_reach.yaml --checkpoint checkpoints/openarm_reach_act/
python scripts/deploy_act_openarm.py --config configs/act_openarm_reach.yaml --checkpoint checkpoints/openarm_reach_act/
```

## 6) Operational Best Practices

- Pin dependency versions.
- Keep scripts idempotent and argument-based.
- Log failures with actionable context.
- Avoid embedding secrets or credentials in code or documentation.
