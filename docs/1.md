# Setup and Execution Workflow

## 1) Environment Preparation

1. Provision an Isaac Launchable environment on NVIDIA Brev.
2. Confirm access to VS Code and Isaac Sim viewer.
3. Clone required upstream repositories into a common workspace.

## 2) Install OpenArm Isaac Extension

Install the OpenArm Isaac Lab extension in editable mode so tasks are discoverable by Isaac Lab scripts.

## 3) Data Collection

1. Select a target OpenArm task.
2. Collect demonstrations with stable control and consistent observation streams.
3. Persist episodes in HDF5 with at least:
   - camera observations
   - joint positions (`qpos`)
   - applied or target actions

## 4) Training

1. Load demonstrations via a dataset adapter that matches ACT expectations.
2. Train ACT using config-driven hyperparameters.
3. Save checkpoints and training metadata for reproducibility.

## 5) Evaluation and Deployment

1. Evaluate checkpoints in the same task configuration used during collection/training.
2. Use chunked action inference for online control.
3. Monitor success metrics and rollout stability before deployment decisions.

## 6) Operational Best Practices

- Pin dependency versions.
- Keep scripts idempotent and argument-based.
- Log failures with actionable context.
- Avoid embedding secrets or credentials in code or documentation.
